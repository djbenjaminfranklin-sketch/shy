## Enregistrement vidéo recommandé 🎥

Enregistre ton écran pendant que tu :
1. Ouvres l'app
2. Swipes 3-4 profils (like + nope)
3. Ouvres un match
4. Envoies un message
5. Vas sur ton profil

Durée : 30-60 secondes suffisent

## Couleurs officielles 🎨

```
Fond principal     : #0D0D0D (noir)
Cartes            : #1A1A1A (gris foncé)
Like              : #00FF88 (vert néon)
Nope              : #FF006E (rose magenta)
Super Like        : #00D4FF (cyan)
Boost             : #8B5CF6 (violet)
Premium           : #FFD700 (doré)
Texte             : #FFFFFF (blanc)
```

---

## Photos de modèles nécessaires 👤

Pour les cartes profil de démo, il faut :
- 4-6 photos de personnes (hommes et femmes)
- Diversité ethnique
- Âge apparent : 25-35 ans
- Style : naturel, souriant, bonne qualité
- Sources gratuites : Unsplash, Pexels (chercher "portrait")

## Comment envoyer au créateur

1. Zip ce dossier `visuels-video`
2. Ajoute les screenshots et vidéo d'écran
3. Envoie avec le prompt détaillé

Ou utilise un service de partage : WeTransfer, Google Drive, Dropbox
